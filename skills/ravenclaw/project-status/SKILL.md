# Project Status

When asked about project status:

1. Read MEMORY.md for the list of active projects
2. For each project, report:
   - Name and one-line description
   - Current status (active, paused, blocked, done)
   - Last activity date
   - Next steps or blockers
3. If a project hasn't been mentioned in 7+ days, flag it as potentially stale
4. Ask if any updates need to be recorded

Present as a clean list, most recently active first.
