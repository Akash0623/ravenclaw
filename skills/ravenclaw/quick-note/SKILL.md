# Quick Note

When the user wants to save a note or reminder:

1. Extract the key information from their message
2. Categorize it (task, idea, reminder, contact, reference)
3. Save to MEMORY.md under the appropriate section
4. If it's time-sensitive, note the date/deadline
5. Confirm what was saved in one short sentence

Keep notes concise. Use bullet points. Always include the date saved.
