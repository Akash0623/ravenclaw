# Daily Briefing

When asked for a daily briefing, provide:

1. **Date & Time** — Current date and time in IST
2. **Weather** — If location context available, brief weather
3. **Calendar** — Any scheduled events or reminders
4. **Project Updates** — Status of active projects from memory
5. **News** — Top 3 relevant AI/tech news headlines (use web search)
6. **Pending Tasks** — Any tasks or follow-ups from previous conversations

Format as a clean, scannable summary. Keep it under 200 words.
